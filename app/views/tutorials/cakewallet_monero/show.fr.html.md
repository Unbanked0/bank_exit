## Pourquoi utiliser un portefeuille souverain ?

Un portefeuille non custodial signifie que vous contrôlez directement vos fonds.

Vous possédez :

- vos clés privées ;
- votre phrase de récupération ;
- la capacité d'envoyer vos fonds sans autorisation d'un intermédiaire.

À l'inverse, laisser vos cryptomonnaies sur une plateforme d'échange signifie que vous dépendez d'un tiers.

## Installer Cake Wallet

### Télécharger l'application

Rendez-vous sur le site officiel: [https://cakewallet.com](https://cakewallet.com)

Cake Wallet est disponible sur plusieurs plateformes :

- Android via Google Play ;
- Android via fichier APK ;
- F-Droid.

Android permet notamment d'installer l'application indépendamment du Play Store grâce au fichier APK.

> [!WARNING]
> Évitez de conserver vos fonds importants sur un portefeuille installé uniquement via un écosystème fermé.

## Créer un nouveau portefeuille

Ouvrez Cake Wallet puis :

1. Acceptez les conditions d'utilisation.
2. Sélectionnez **Créer un nouveau portefeuille**.
3. Définissez un code PIN.

Ce code PIN protège uniquement l'application sur votre téléphone.

> [!WARNING]
> N'utilisez pas le même code que celui de votre téléphone.

## Choisir Monero

Cake Wallet permet de gérer plusieurs cryptomonnaies.

Pour ce tutoriel :

1. Sélectionnez **Monero (XMR)**.
2. Donnez un nom à votre portefeuille.
3. Choisissez le format de sauvegarde :

- **Legacy 25 mots** ;
- langue française.

## Sauvegarder votre portefeuille

Cake Wallet va afficher une phrase de récupération de 25 mots.

Ces mots permettent de restaurer votre portefeuille :

- sur un nouveau téléphone ;
- après une perte ou un changement d'appareil.

## Règles importantes

✅ Notez ces mots sur papier.

Encore mieux :

- utilisez une plaque métallique résistante ;
- conservez plusieurs copies dans des endroits sécurisés.

❌ Ne faites pas de capture d'écran.

❌ Ne stockez pas cette phrase dans un cloud.

❌ Ne partagez jamais ces mots.

Toute personne possédant cette phrase possède votre portefeuille.

## Configurer l'affichage en euros

Par défaut, Cake Wallet peut afficher les montants en dollars.

Pour passer en euros :

1. Ouvrez les paramètres.
2. Allez dans **Affichage**.
3. Sélectionnez **EUR** comme devise.

## Recevoir des Monero

Dans Cake Wallet :

1. Cliquez sur **Recevoir**.
2. Copiez votre adresse Monero.
3. Partagez-la avec la personne qui doit vous envoyer des XMR.

Vous pouvez également utiliser le QR code.

Les deux méthodes correspondent à la même adresse.

## Envoyer des Monero

Pour envoyer des XMR :

1. Cliquez sur **Envoyer**.
2. Saisissez l'adresse du destinataire.
3. Indiquez le montant.
4. Ajoutez éventuellement une note.
5. Validez la transaction.

Vous pouvez scanner directement un QR code pour éviter les erreurs.

### Les frais de transaction

Les frais Monero sont généralement très faibles.

Cake Wallet permet d'ajuster le niveau de priorité de la transaction selon votre besoin de rapidité.

## Confirmation d'une transaction

Une transaction apparaît rapidement après son envoi.

Cependant :

- elle doit ensuite être confirmée par le réseau ;
- le solde peut rester temporairement indisponible pendant la synchronisation.

Vérifiez que Cake Wallet est correctement synchronisé avant d'effectuer un paiement.

## Acheter du Monero avec des euros

Cake Wallet permet d'acheter du Monero directement depuis l'application.

### Procédure

1. Cliquez sur **Acheter**.
2. Choisissez le prestataire disponible.
3. Sélectionnez le montant souhaité.
4. Effectuez le virement bancaire demandé.

Votre adresse Monero est automatiquement utilisée pour recevoir les fonds.

### À propos des achats

Selon le montant et le prestataire, une procédure de vérification d'identité peut être demandée.

Les frais varient généralement entre 1 et 3 %.

## Dépenser ses Monero

Monero peut être utilisé auprès de certains commerçants.

Pour trouver des commerces acceptant les cryptomonnaies :

- utilisez la carte Sortie de Banque ;
- recherchez les commerces proches de chez vous.

Si aucun commerce n'accepte directement Bitcoin ou Monero dans votre région, des services comme Bitrefill permettent d'utiliser des cryptomonnaies pour acheter certains services et cartes cadeaux.

## Les bonnes pratiques de sécurité

Pour rester souverain :

- gardez toujours votre phrase de récupération hors ligne ;
- vérifiez les adresses avant d'envoyer une transaction ;
- maintenez votre application à jour ;
- n'utilisez jamais un portefeuille dont vous ne possédez pas les clés.

## Conclusion

En quelques étapes, vous disposez maintenant :

- d'un portefeuille Monero personnel ;
- de la capacité d'envoyer et recevoir des paiements ;
- d'un moyen d'acheter du XMR ;
- d'une solution pour utiliser vos fonds directement chez certains commerçants.

La souveraineté financière commence par le contrôle de ses propres clés.
