## 1. Contexte économique présenté

### Constats évoqués

Selon les intervenants, plusieurs risques économiques sont à surveiller :

- 📉 Dette publique élevée
- 🏭 Désindustrialisation et dépendance extérieure
- 💶 Risque d’inflation et de perte de pouvoir d’achat
- 🏦 Fragilité potentielle du système bancaire
- 💳 Développement des monnaies numériques de banque centrale (CBDC)

### Critiques évoquées sur l’euro numérique

Les intervenants expriment des inquiétudes concernant :

- La traçabilité complète des paiements
- Une possible perte d’anonymat financier
- Une dépendance accrue aux institutions centrales

## 2. Les critères d’un bon moyen d’échange

Le collectif présente plusieurs critères recherchés :

1. ✅ Ne pas créer une nouvelle monnaie officielle
2. ✅ Être décentralisé
3. ✅ Être souverain (contrôlé par les utilisateurs)
4. ✅ Être difficile à censurer
5. ✅ Être simple et rapide à utiliser
6. ✅ Pouvoir fonctionner à grande échelle

## 4. Bitcoin : réserve de valeur numérique

### Principes

Bitcoin est présenté comme :

- Une blockchain publique mondiale
- Un réseau sans autorité centrale
- Une réserve de valeur numérique

### Fonctionnement simplifié

Une blockchain peut être comparée à un grand fichier partagé entre des milliers d’ordinateurs. Chaque transaction ajoute une nouvelle ligne dans ce fichier, synchronisée partout.

### Points forts

✅ Décentralisé
✅ Résistant à la censure
✅ Fonctionne 24h/24
✅ Offre limitée dans le code

### Limites

⚠️ Bitcoin est transparent :

- Les transactions sont visibles publiquement
- Il est moins adapté aux paiements privés du quotidien

## 5. Monero : paiement privé

### Présentation

Monero est présenté comme une cryptomonnaie orientée :

- 🔒 Confidentialité
- 🕵️ Protection de la vie privée
- 💸 Paiements du quotidien

### Différences avec Bitcoin

| Bitcoin                  | Monero                       |
| ------------------------ | ---------------------------- |
| Plutôt réserve de valeur | Plutôt moyen d’échange       |
| Transactions visibles    | Transactions privées         |
| Plus connu               | Plus orienté confidentialité |

## 6. Créer un portefeuille Bitcoin

### Application présentée

Relai Bitcoin Walletrelai.app

Étapes :

1. Installer l’application
2. Créer un portefeuille
3. Choisir un code PIN différent du téléphone
4. Sauvegarder les mots de récupération

### ⚠️ Sécurité essentielle

Les mots de récupération :

- 🔑 donnent accès aux fonds
- ❌ ne doivent jamais être partagés
- ❌ ne doivent pas être envoyés par email
- ✅ doivent être conservés hors ligne

Exemples :

- Papier
- Plaque métallique gravée
